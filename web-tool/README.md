# TinyDays 网页版试用候选

01 天数印章和 03 月龄印章使用同一个 `/web-tool/` 链接。输入已激活的邀请码，网页调用同域 `POST /api/web-tool/access`，获取实际模板与只读 Day 1 日期。原激活及找回流程不变。历史同时拥有 01 和 03 的码默认打开 03。

本目录从已试用的 PR #6 演进。正式候选与 TinyDays 后端、Caddy 和统一激活页配套。必须同时提供新访问接口、原有印章接口、激活页手写字和视觉素材。生产无需迁移 SQLite 架构。

| 验收项 | 检查方法 |
| --- | --- |
| 邀请码 | 在同一个链接分别输入已激活的 01 和 03，核验标题、原 Day 1 日期和盖章结果。核验无效、失效、未激活。 |
| iPhone Safari | 覆盖 JPEG、HEIC、截图、转存图、横竖图、高分辨率和 1、20、21 张选图。 |
| 日期与重试 | 对照原图补上日期和验证早于 Day 1 的提示。模拟单张失败并只重试失败项。 |
| 保存 | 检查单张和批量系统分享、存到相册、取消及逐张保存降级。 |
| 隐私 | 验证访问请求只发送邀请码，盖章只发送邀请码、照片日期及模板编号。禁止图片上传、缓存访问响应或记录邀请码和客户日期。 |
| 回归 | 验证原有两款快捷指令、激活、找回、页脚及撤回网页入口。 |
