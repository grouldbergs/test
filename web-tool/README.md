# TinyDays 月龄印章网页版试用

本目录从已试用的 PR #6 合并提交 `7d12b02b6b2a1af805897d7a1b82ee61cc451b49` 的 `docs/` 原型延伸。候选页与 TinyDays 激活及盖章 API 部署在同一 HTTPS 源下，路径为 `/web-tool/`。本目录独立于 GitHub Pages 的原型目录。

在与上海生产基线一致的测试环境中，把 HTML、CSS 和 JS 放到 Caddy 静态根目录的 `web-tool/`，同时应用 TinyDays 生产项目的 Caddy 和激活入口改动。浏览器向现有 lookup 和 stamp 发送 POST JSON，叠加过程使用本地文件和 Canvas。请先完成下面的验收，再开放顾客入口。

| 验收项 | 检查方法 |
| --- | --- |
| 兑换及找回 | 分别用新码激活 03、用旧 03 码找回。两处均进入网页工具。无效码、失效码、未激活码和仅 01 权益显示对应提示。核验同一照片与快捷指令月龄一致。 |
| iPhone Safari | 从照片图库选 JPEG、HEIC、转存图和截图，覆盖横竖图、高分辨率、1 张、20 张和 21 张。记录浏览器实际收到的格式、方向、日期来源、处理耗时和导出尺寸。 |
| 日期及重试 | 缺日期的照片预览后补填。模拟弱网和单张错误，确认已完成成片可保存，重试不会重新生成成功项。 |
| 保存 | 验证系统分享的单张和 20 张保存到相册、取消、批量失败降级和下载位置。说明中写明静态 JPEG、尺寸和实况支持。 |
| 隐私 | 检查网络中的全部请求。API JSON 只包含兑换码、日期与模板 ID 必要字段。检查设备照片、原始文件名和激活日期均未发送，兑换码未进入 URL 或日志。 |
| 回归 | 核验 01/03 原有激活、找回、快捷指令盖章与页脚。验证能撤回网页版链接和静态资源。 |

客服话术

- 找不到拍摄日期时，可以对照原图补填日期，再生成水印。
- 点「分享或下载这张」后，如果弹出系统分享，请选「存储图像」并到相册确认。下载的成片可在浏览器下载项目中查看。
- 目前试用支持已激活的月龄印章。你也可以在激活页输入原来的兑换码，找回对应的快捷指令。
